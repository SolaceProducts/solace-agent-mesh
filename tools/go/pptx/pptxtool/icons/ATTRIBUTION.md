# Icon attribution

The `.png` glyphs in this directory are derived from **Bootstrap Icons**
v1.13.1 (https://github.com/twbs/icons), licensed under the MIT License
(see `LICENSE`).

Each source SVG was recolored to the Solace navy `#0A1622` and rasterized
to a 256×256 transparent PNG. File names are Solace-internal semantic stems
(e.g. `database.png`, `rocket.png`) mapped from Bootstrap icon names; the
mapping and regeneration recipe live in the repo's PR history.

No Bootstrap Icons source is modified beyond the fill color and format.
